# PlayStation button icon attribution

The four PlayStation button glyphs are rasterized from the `ps_x`, `ps_circle`, `ps_square`, and `ps_triangle` artwork in [flat-gamepad-icons](https://github.com/RobTheFiveNine/flat-gamepad-icons), by RobTheFiveNine.

The artwork is licensed under the Creative Commons Attribution-ShareAlike 4.0 International license (CC BY-SA 4.0): https://creativecommons.org/licenses/by-sa/4.0/

The original source is retained in `ps4-gamepad-icons.svg`. The generated RGBA icon data is a derived work distributed under the same license.

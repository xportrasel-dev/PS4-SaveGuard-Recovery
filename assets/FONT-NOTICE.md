# Dashboard font attribution

The anti-aliased dashboard text atlas is generated from DejaVu Sans Bold, supplied by Ubuntu's `fonts-dejavu-core` package. DejaVu is based on Bitstream Vera; the DejaVu changes are in the public domain. The complete upstream license is included in `DejaVu-LICENSE.txt`.

The atlas contains only the uppercase Latin letters, digits, and space used by the current dashboard. The font file itself is not bundled in the PS4 application.
